# Chat_bot
My first Chatbot


🤖 ChatGPT Q&A Bot – Python Project
This is my first Python project – a simple ChatGPT-based Q&A bot! 🎉
It features a collection of pre-defined (ready-made) questions that users can ask, and the bot responds using OpenAI's language model.

🔧 Features
Interactive chatbot interface in the terminal
Preloaded with common or fun questions
Uses OpenAI's GPT API to generate responses
Clean and beginner-friendly Python code
